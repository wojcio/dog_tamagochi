🐕 Dog Tamagotchi 2D C + BITMAP NES

Napisane w C (CC65 + neslib/nesdoug) z grafiką bitmapową i płynnym scrollingiem 4 biomów
🎮 Gra uruchomiona (60 FPS)
🌲 1. Ogród i Buda  |  🌉 2. Park z Mostkiem  |  🏖️ 3. Słoneczna Plaża  |  🏆 4. Tor Agility

🕹️ Sterowanie (Pad NES):

← / → lub A / D : Ruch pieska
Z / Spacja / W : Skok (Przycisk A)
X lub B : Szczekanie HAU! (Przycisk B)
↓ lub S : Sen w budzie 💤 (Dół)
Enter : START
Shift : SELECT
