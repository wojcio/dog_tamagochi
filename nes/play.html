🐕 Dog Tamagotchi 2D (NES Edition)

Kolorowa platformówka ASCII w czystym asemblerze 6502 dla Nintendo NES
🎮 Wczytywanie gry...

🕹️ Klawiszologia Pad NES:

← / → lub A / D : Ruch pieska
Z / Spacja / W : Przycisk A (Skok)
X lub B : Przycisk B (Szczekanie HAU!)
↓ lub S : Dół (Sen w budzie 💤)
Enter : START
Shift : SELECT
